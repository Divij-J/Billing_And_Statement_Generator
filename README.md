## Business Overview
The application enables end‑to‑end credit card billing by:
1. Tracking all customer transactions
2. Calculating interest and applicable fees
3. Generating monthly statements
4. Computing minimum due amounts
5. Handling payments & carry‑forward balances

## Key Application Features
* Card Issuance
* Transaction Management
* Billing Date Processing
* Interest Rules - Standard Purchase Interest, Cash Advance Interest, Late Payment Fee
* Minimum Due Calculation
* Monthly Statement Output
